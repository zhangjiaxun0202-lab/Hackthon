# Warm Liquid Glass 视觉规范

## 方向

目标是把 Beauty Archive 做成暖棕色的 Liquid Glass 网页原型：内容保持清晰，导航、按钮、弹层和关键卡片形成悬浮的玻璃层；页面切换时让内容和玻璃层顺滑衔接。

## 色彩

| 用途 | 色值 |
| --- | --- |
| 画布背景 | #e8e0d5 |
| 页面底色 | #faf7f2 |
| 玻璃卡片 | rgba(240,232,221,.55) |
| 深咖主操作 | #301b10 |
| 深咖正文 | #31231a |
| 焦糖强调 | #aa8b76 |
| 辅助文字 | #907466 |

## 材质

- 玻璃表面使用半透明渐变、白色内高光、柔和阴影和 backdrop-filter: blur(...)。
- 导航使用悬浮圆角岛，激活项使用深咖填充。
- 主 Hero、画像和导师卡片使用深咖到焦糖的渐变，并保留照片透出。
- 不支持 backdrop-filter 时回退到不透明的米白卡片，保证文字可读。

## 动效

- 页面切换：内容先淡出、轻微缩小和模糊，再淡入到目标页面。
- 弹层：遮罩淡入，底部面板上浮并回到稳定圆角。
- 导航：激活胶囊缩放进入，按钮颜色和阴影缓动。
- 按压：卡片和按钮短暂缩小，给出明确触感反馈。
- prefers-reduced-motion: reduce 时关闭自定义动画。

## 实现位置

- liquid-glass.css：主题变量、玻璃材质、导航、卡片和转场。
- app.js：路由渲染令牌、页面切换调度和资源缓存版本。
- index.html：视觉系统说明、色板和主题资源版本号。

## 参考原则

这套网页实现参考 Apple 的 Liquid Glass 材质原则：玻璃主要承担导航和控件层，内容在其下方滚动并保持可读；交互控件在激活和转场时提供响应式变化。网页版本是视觉近似，不等同于原生 SwiftUI 的 glassEffect、glassEffectID 或系统级材质。
