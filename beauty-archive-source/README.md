# Beauty Archive｜我的美妆图鉴

一个面向手机浏览器的美妆收藏、妆容记录与达人匹配交互原型。使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 本地运行

下载或克隆仓库后，用浏览器直接打开 `index.html`。

也可以在项目目录运行静态服务器，例如已安装 Python 时执行：

```sh
python -m http.server 8000
```

然后打开 http://localhost:8000。

## 演示路径

1. 首页 → 添加产品 → 体验批量识别演示 → 核对信息 → 加入图鉴。
2. 首页 → 记录今日妆容 → 选择产品 → 保存，联动更新使用次数、搭配次数、积分与风格足迹。
3. 达人匹配 → 按肤色或风格筛选 → 达人详情 → 分步教程 → 跟练记录。

支持产品搜索、分类、手动录入、产品详情、画像编辑、关注达人、成长徽章与演示数据重置。

## 项目结构

```text
index.html   页面、样式、交互逻辑及初始演示数据
README.md    使用与开发说明
.gitignore   本地文件排除规则
```

修改 `index.html` 中的 `<style>` 可调整界面；修改 `<script>` 中的 `initial`、`additions`、`teachers` 可调整初始产品和达人示例。

## 部署

这是静态网页。可部署到 Netlify、GitHub Pages 或其他静态托管服务。入口文件为根目录的 `index.html`，不需要构建步骤。

## 数据与演示边界

- 产品、达人、教程与匹配信息为演示数据，不代表品牌官方商品资料或真实达人。
- 批量识别使用固定结果，没有连接真实 AI 识别服务。
- 所选照片仅用于当前浏览器本地预览，不上传服务器。
- 记录保存在当前浏览器的 localStorage 中，不会跨设备同步。清除浏览器数据会移除记录。
- 没有真实账号系统、订单同步、积分兑换或第三方接口。
- 品牌名称与标识权利归各自权利人所有；本项目不表示与品牌存在合作或获得其认可。
